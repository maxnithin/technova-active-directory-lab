# TechNova Enterprise Active Directory Lab

Enterprise Infrastructure Engineering project built using Windows Server 2022, Active Directory, DNS, Group Policy, PowerShell and Windows 10.

## Project Overview

This project simulates a real enterprise environment where a System Administrator deploys and manages an on-premises Active Directory infrastructure.

## Technologies

- Windows Server 2022
- Windows 10
- Active Directory Domain Services
- DNS
- Group Policy
- PowerShell
- Oracle VirtualBox

## Project Phases

| Phase | Description |
|--------|-------------|
| 1 | Domain Controller Deployment |
| 2 | Organizational Units |
| 3 | Domain Join & User Management |
| 4 | Group Policy |
| 5 | File Shares & NTFS Permissions |
| 6 | Folder Redirection |
| 7 | PowerShell User Automation |
| 8 | 513 User Enterprise Onboarding |

## Results

- Deployed TECHNOVA.LOCAL domain
- Joined CLIENT01 to Active Directory
- Created departmental OUs and Security Groups
- Configured Group Policy
- Implemented File Shares and Folder Redirection
- Automated onboarding of 513 users using PowerShell
